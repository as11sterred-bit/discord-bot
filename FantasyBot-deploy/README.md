# FantasyRP Discord Bot

Discord-бот с навигационной панелью для сервера FantasyRP.

## Переменные окружения

- `DISCORD_TOKEN` — токен бота из Discord Developer Portal.
- `TICKET_CHANNEL_ID` — ID канала помощи (необязательно, по умолчанию `0`).

Секретные значения задаются в панели Bothost и не добавляются в GitHub.

## Запуск

```bash
python bot.py
```
